🚀 Mise en route en 4 étapes

  1. Installer les dépendances : npm install
  2. Copier le fichier de config : cp .env.example .env
  3. Remplir les clés API dans .env :
       • aviationstack.com — API de suivi de vol (gratuit 500 req/mois)
       • twilio.com — SMS & WhatsApp (essai gratuit)
  4. Lancer le serveur : npm start  →  http://localhost:3000
